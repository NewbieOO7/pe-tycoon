# PE Tycoon

A private equity roguelite for your phone. Raise a fund, buy companies, fix them, flip them or strip them for parts, survive the boss at the end of each fund, and retire rich, or go to prison trying.

**Play:** https://newbieoo7.github.io/pe-tycoon/

## Files

- `pe-tycoon.html`: the game source (latest version).
- `versions/`: a frozen copy of every version.
- `index.html` and `play/`: the playable site, generated by `python build.py`.

Saves live in your browser, so a run started on one device stays on that device.
